# AnishopSPA
SPA internet-shop Django/React

Технологический стек:
🔹 Backend: Django + Django REST Framework (API)
🔹 Frontend: React (Next.js) 
🔹 База данных: PostgreSQL
🔹 Оплата: ?
🔹 Реактивность: WebSockets (Django Channels) для анимации рулетки

core: Главная страница и общая логика.
products: Товары и категории.
cart: Корзина.
orders: Заказы, оплата, доставка.
roulette: Рулетка бонусов.
users: Пользователи, регистрация, личный кабинет.
